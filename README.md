- Сердечки сохраняются только в localStorage посетителя, без общего счётчика и сервера. Очистка данных браузера сбрасывает отметки.

Копирование использует Clipboard API и резервное выделение/копирование текста; при отказе браузера текст можно скопировать вручную.
- Изображения увеличиваются по клику; стрелки клавиатуры листают доступные работы, Escape закрывает просмотр. Фильтры: все / квадратные / горизонтальные.

## Где редактировать

content.js — контакты, словари copy.ru / copy.en, подписи и истории projects[].ru / projects[].en. В story три абзаца: контекст, анализ, решение. Общие image и url — путь к изображению и кейс Behance. Ссылки на источники не публикуются в данных, карточках и увеличенном просмотре.

style.css — оформление. index.html — структура и статическая английская версия для просмотра без JavaScript. При изменении состава галереи или резервных текстов синхронизируйте index.html. При замене изображения можно сохранить его имя в assets/creatives. Файлы используют относительные пути и работают в подпапке домена.

assets/fonts — локальный Manrope и лицензия SIL OFL. Внешние сервисы, аналитика, удалённые шрифты и зависимости не подключаются. Кнопка Email запускает почтовое приложение; формы и серверной отправки нет.
