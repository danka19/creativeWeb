## Проблема → изменение → проверка

| Проблема / потребность | Минимальное изменение | Проверка |
|---|---|---|
| Доступные дубликаты `/` и `/index.html` без указания основного адреса | Один абсолютный canonical на реальный HTTPS-корень в исходном HTML | В браузере и HTML ровно один правильный canonical; JS его не меняет |
| Нужен явный список URL для подачи нового сайта поисковикам | sitemap.xml с единственной главной страницей; robots.txt указывает sitemap и сохраняет разрешающий обход режим | XML разобран; URL совпадает с canonical; правила разрешают Googlebot, bingbot, OAI-SearchBot |
| 23 PNG занимают 15 058 866 байт | Добавлены WebP lossless: 8 744 894 байта; ссылки синхронно обновлены в HTML и content.js | Экономия 6 313 972 байта (41,9%); декодированные RGBA-пиксели всех 23 файлов идентичны; размеры неизменны |
| README ошибочно называл сайт неопубликованным | Зафиксированы подтверждённый адрес, текущий статус и ограничения публикации | Адрес проверен HTTP-запросами, новая ветка ещё не размещена |

PNG сохранены без изменений рядом с WebP. Меньше стал объём загружаемых изображений, а не размер репозитория. Визуально просмотрены desktop/mobile, первый экран и текстовый креатив Expel до/после; потери читаемости из-за конвертации нет. Исходное ограничение детализации копий 720 px осталось.

Canonical на текущем этапе консолидирует одну английскую HTML-страницу, включая параметризованные варианты. Это намеренно **не** решение для отдельного русского поискового присутствия. При выделении статических RU/EN нужны собственные canonical, взаимные hreflang и обновлённая sitemap; нельзя механически оставить canonical RU на английский корень. Языковые ссылки и поведение пользователя сейчас не изменены.

Sitemap полезна как конкретный файл для подачи и обнаружения нового сайта, но не обязательна для обхода одной страницы. В ней нет якорей, `?lang`, вымышленных lastmod, priority или частоты обновления. Robots.txt не служит защитой приватных файлов. Он не вводит нового запрета GPTBot: прежний разрешающий режим сохранён. Поисковый OAI-SearchBot и обучающий GPTBot — независимые правила; открытие поиска не требует разрешать обучение. Отдельное решение об обучении в этой задаче не принималось.

Структурированные данные и llms.txt не добавлялись: конкретной дополнительной пользы для этого одностраничного портфолио не установлено. Новые услуги, кейсы, обещания, отзывы и референсные ссылки не добавлены. Дизайн, тексты, script.js и style.css не изменены.
